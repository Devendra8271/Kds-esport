# KDS E-sports

## Files
- `server.js` — Node/Express API + player/admin logic
- `player.html` — Player portal
- `admin.html` — Master Admin dashboard
- `Code.gs` — Google Apps Script email + Google Sheets sync
- `package.json` — Render/Node dependencies
- `render.yaml` — Render deployment configuration
- `kds-logo.svg` — KDS logo
- `default-avatar.svg` — default player avatar

## Render environment variables
Set:
- `ADMIN_PASSWORD` = a new strong password (do not commit it)
- `PUBLIC_URL` = your Render URL, e.g. `https://your-app.onrender.com`
- `ADMIN_TOKEN` is generated by `render.yaml`
- `APPS_SCRIPT_URL` is already set to the supplied Apps Script endpoint.

## Google Apps Script
1. Open Apps Script.
2. Paste `Code.gs`.
3. Deploy as Web app, Execute as you, Who has access: Anyone.
4. Optional: create Script Property `SHEET_ID` with your Google Sheet ID.
5. Optional: create Script Property `SHEET_NAME` (default `KDS_Data`).

## Important production note
The included JSON store is suitable for a simple prototype/demo. Render's local filesystem is not a durable database across all deployments/restarts. For real money/wallet production, move the data layer to PostgreSQL/another persistent database and add rate limiting, CSRF protection, HTTPS-only cookies, audit controls, and legal/compliance review.
